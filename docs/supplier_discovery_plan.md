# 异采 · 供应商发现与智能匹配 产品方案 v1.0

## 一、功能概述

为品牌方端增加供应商发现能力，分两层实现：

### 第一层：供应商橱窗
- 品牌方可浏览、搜索、筛选供应商
- 查看供应商公开主页（公司简介、产品、资质）
- 一键联系供应商（发起询盘）

### 第二层：智能匹配
- 发布询盘时自动推荐匹配供应商
- 公开询盘对匹配供应商可见，供应商可主动应标
- 品牌方在报价对比视图中选择最优报价

## 二、信息架构

### 供应商发现页（原"供应商列表"页升级）
- 顶部搜索栏 + 筛选标签（品类/地区/认证/精选）
- 供应商卡片列表（含产品缩略图、品类标签、认证状态）
- 精选供应商置顶展示

### 供应商公开主页（新页面）
- 公司基本信息：名称、地区、成立年份、规模
- Tab切换：公司简介 | 产品/服务 | 资质证书
- 底部固定"联系供应商"按钮

### 询盘发布-智能推荐
- 选择品类后自动推荐匹配供应商
- 推荐逻辑：品类匹配 > 地区匹配 > 认证优先 > 精选优先
- 推荐结果可一键勾选，批量发送询盘

## 三、数据来源

| 数据 | 表 | 说明 |
|------|-----|------|
| 供应商档案 | suppliers | 公开字段（company_name, region, category, description等） |
| 供应商产品 | products | 公开字段（name, category, description, price_range等） |
| 询盘 | inquiries / buyer_inquiries | 品牌方发布 |
| 报价 | inquiry_quotes / supplier_quotes | 供应商应标 |

## 四、技术方案

### 前端（品牌方端 yicai-buyer）
1. **suppliers.js** 重写 → 供应商发现+搜索+筛选
2. 新增 **supplier-detail** 模块 → 供应商公开主页
3. **inquiries.js** 增强 → 发布时智能推荐匹配供应商
4. **index.html** 新增页面和模态框

### 数据库
1. 创建 `public_supplier_profile` 视图 → 聚合供应商+产品数据
2. 创建 `match_suppliers_for_inquiry` RPC → 智能匹配函数
3. 确保 products 表对品牌方可读（RLS 已开放）

### 匹配算法
```
权重 = 
  品类完全匹配 × 40分 
+ 地区匹配 × 20分 
+ 已认证 × 20分 
+ 精选供应商 × 15分 
+ 评分 × 5分
```

## 五、交互流程

### 发现供应商
1. 品牌方点击底部Tab"发现" → 进入供应商橱窗
2. 搜索/筛选 → 浏览供应商卡片
3. 点击卡片 → 进入供应商公开主页
4. 查看产品/资质 → 点击"联系供应商"
5. 弹出询盘表单（自动带入供应商信息）→ 发送

### 发布询盘（智能匹配）
1. 品牌方点击"发布询价"
2. 填写品类、需求描述
3. 系统自动推荐匹配供应商（显示在表单下方）
4. 品牌方可勾选推荐供应商 → 一键发送
5. 供应商收到询盘 → 报价 → 品牌方对比选择
