# 异采 YiCai · 采购方端

新锐品牌方的供应链平台 - 采购方 Web App

## 功能

- 📝 发布采购需求（支持匿名发布、披露控制）
- 📋 需求管理（编辑、关闭、查看报价）
- 💰 查看供应商报价（接受/拒绝）
- 📦 订单管理（查看生产进度）
- 👤 个人中心（企业档案、账号设置）

## 技术栈

- 纯前端 SPA（HTML + CSS + JavaScript）
- Supabase（认证 + 数据库 + RLS）
- 移动端优先设计
